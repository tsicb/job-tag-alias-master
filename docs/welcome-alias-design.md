# 歓迎系 alias 設計

## 目的

求人原稿で「歓迎」を直接使わず、OK・可・積極採用・活躍中などへ言い換える表現を、意味の強さを保ったまま求人タグへ結びつける。

## Confidence

| 原稿表現 | X歓迎に対する扱い |
| --- | --- |
| X歓迎 | canonical / 元alias |
| XOK | strict |
| X大歓迎 | strict |
| X積極採用 | strict |
| X可 | loose（個別例外あり） |
| Xも可 | X可と同じconfidence |
| X活躍中 | 一括追加しない。原則loose候補 |
| X在籍 | 一括追加しない。原則loose候補 |

## 複合属性

A・B歓迎のようなタグでは、AとBの両方を残す表記揺れはstrict、AまたはBだけの記載はloose。

## 活躍中 / 在籍

この2種類は「現在その属性の人がいる」という職場事実であり、「その属性からの応募を歓迎する」とは意味が異なる。

別canonicalがある場合は統合しない。

現行の独立例:

- 派遣社員活躍中
- 外国人活躍中
- 女性活躍中
- 幅広い年代活躍中
- 留学生活躍中
- 障がい者活躍中

将来の検討候補:

- フリーター活躍中 / 在籍
- 主婦・主夫活躍中 / 在籍
- シングルマザー・ファーザー活躍中 / 在籍
- 子育て世代活躍中 / 在籍

これらは個別に意味を確認し、別canonicalがない場合のみloose候補として検討する。

## 属性 + 応募 の派生

大量のalias文字列をSheetへ保存せず、matcherで動的派生する。

| 基底表現 | 派生表現 | confidence |
| --- | --- | --- |
| X歓迎 (strict) | X応募歓迎 | strict |
| X歓迎 (strict) | X応募OK / Xも応募OK | strict |
| X歓迎 (strict) | X応募可 / Xも応募可 | loose |
| X歓迎 (strict) | X応募可能 / Xも応募可能 | loose |
| X歓迎 (loose) | 上記すべて | loose |

派生元は基底の `歓迎` 表現に限定し、`大歓迎` や既に `応募歓迎` になった派生表現から再帰生成しない。

このルールは「求職者属性・経験条件」を対象にした応募歓迎タグ専用であり、LINE/Web/電話など応募方法には適用しない。
