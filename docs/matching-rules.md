# マッチングルール

## 基本思想

求人の意味に沿ったタグ候補を安定して抽出する。誤爆コストが高い項目は保守的に扱う。

## match_policy

### normal
canonical / alias_strictを通常判定する。除外語や、より具体的な表現の優先順位を併用する。

### context
単語だけで意味や関係性が確定できないタグ。

主な対象:
- 採用
- 介護
- 認証
- 候補
- 就業場所カテゴリの施設・場所タグ

就業場所は `勤務地`、`勤務先`、`配属先`、`施設内勤務` などの関係性を要求する。

### pattern
数値・形式・閾値で判断する。

現行7件:
- 年間休日120日以上
- 残業月平均20時間以上
- 残業月平均20時間以内
- 固定給25万円以上
- 固定給35万円以上
- 1日4時間以内OK
- 駅近5分以内

`1日4時間以内OK` は「1日N時間以内／まで」の明示時のみN<=4で判定する。単なる勤務時間から推測しない。

`駅近5分以内` は駅名または最寄駅と徒歩N分の関係が明示された場合のみN<=5で判定する。

### token_exact
短い英数字タグをraw substringではなくトークン境界で判定する。

境界ルール:
- 前後がASCII英数字でないことを基本とする。
- 日本語との直結は許容する。例: `AWS経験` はAWSとして有効。
- `JavaScript` からJava、`GitHub` からGit、`SCSS` からCSSは付与しない。

### strict_only
予約済み。第3版レビューでは一括採用していない。

## 除外語

除外語は文書全体ではなく、canonical / aliasと重なる・近接する誤爆箇所へ局所適用する。

例:
- `接客なし` 内の「接客」
- `英語力不要` 内の「英語」
- `長期休暇` 内の「長期」
- `整体院` 内の「整体」
- `透析施設` 内の「透析」
- `サービス残業なし` 内の「残業なし」
- `家族誕生日休暇` 内の「誕生日休暇」

同じ本文の別箇所に有効な表現があれば、その出現は独立して判定する。

## aliasで処理する数値風表現

数値が含まれていても、閾値比較が危険なものはpattern化しない。

- `週4日以上OK`: 週5日固定を数学的に「4日以上OK」と推測しない。明示表現をstrict aliasで補強。
- `18歳以上`: 20歳以上等を18歳以上タグへ自動変換しない。18歳～ / 18歳から等をstrict aliasで補強。
