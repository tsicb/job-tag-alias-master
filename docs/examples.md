# 判定例

## aliasで拾う例

| 求人内表現 | タグ | 扱い |
|---|---|---|
| 通勤手当あり | 交通費支給 | strict alias候補 |
| 家賃補助あり | 住宅手当あり | strict alias候補 |
| GW休み | ゴールデンウィーク休暇あり | strict alias |
| 時間外労働なし | 残業なし | strict alias |
| 時間外手当 | 残業手当あり | strict alias |

## contextで抑止したい例

| 求人内表現 | 単純一致するタグ | 望ましい扱い |
|---|---|---|
| 採用人数2名 | 採用 | 自動確定しない |
| 介護休暇あり | 介護 | 介護スキルとしては抑止 |
| 病院へ医薬品を配送 | 病院 | 就業場所としては抑止 |
| 海外勤務あり | 海 | 就業場所としては抑止 |
| 接客なし | 接客 | 接客スキルとしては抑止 |
| 英語力不要 | 英語 | 言語スキルとしては抑止 |

## patternで拾う例

### 残業

`時間外労働：月平均10時間`

→ `残業月平均20時間以内` の候補。

### 年間休日

`年間休日125日`

→ `年間休日120日以上` の候補。

### 固定給（設計方針）

`固定給26万円`

→ `固定給25万円以上` の候補。

`月給26万円`

→ 固定給タグには変換しない。

## より具体的な語を優先する例

`JavaScript経験者`

→ `JavaScript` は候補。単純substringだけを根拠に `Java` まで自動付与しない。

`GitHubを利用`

→ `GitHub` と `Git` の意味関係を別途定義しない限り、substringだけで `Git` を付与しない。
